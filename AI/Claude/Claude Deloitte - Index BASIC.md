## 1. INTRODUCTION - BASIC
### 1.1 What are Claude Code, Codex, and/or Copilot, and what will I learn?

Claude Code, Codex, and GitHub Copilot are AI-assisted development tools that allow us to integrate AI models into our programming workflow.

Instead of using AI solely to generate code snippets, these tools can **analyze a project, understand its structure, modify files, execute commands, and help us implement complete features**.

In this module, you will learn the fundamental concepts for getting started with coding agents:

- What Claude Code, Codex, and GitHub Copilot are.
- The difference between a code assistant and an agent.
- How to interact effectively with an agent.
- How to provide context and instructions.
- How to review and oversee its changes.
- How to use the main operating modes.
- How to incorporate these tools into a standard development workflow.

The goal is to shift from **"asking AI for code"** to working with it as an assistant capable of actively participating in a project's development.

### 1.2. What is an agent and the "agentic loop"?
An AI agent does not simply respond to our instructions. It can **observe the environment, reason about a task, use tools, and evaluate results** to progress toward a goal. This process is known as the **agentic loop**.

Simply put:

1. The agent analyzes the context.
2. It determines what needs to be done.
3. It uses available tools.
4. It checks the result.
5. It repeats the process if necessary.

For example, given a request like:

> "Add an authentication system and run the tests."

The agent can inspect the project, locate the current system, modify several files, install dependencies, run the tests, and fix any errors found.

We will learn to **understand this cycle, supervise it, and provide instructions that yield better results**.
